# Cosmic Digital Library 📚🎬🎧

A premium Streamlit application that dynamically indexes, streams, and downloads books, audio files, and videos directly from Google Drive via Rclone.

## Features
- **Dynamic Content Updates:** Changes to Google Drive folders reflect immediately on refresh.
- **In-Browser Streaming:** Directly streams video and audio content.
- **Glassmorphism Theme:** Beautiful, dark-mode focused modern UI.
